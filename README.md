# 🤍 Mother

A full-stack application rooted in the idea of "Mothering the Mother."

Designed with postpartum recovery and maternal well-being in mind, Mother explores how technology can support parents in caring for themselves while navigating the everyday work of caring for their families.

## **About**

Mother aims to shift the focus of postpartum care toward the person doing the caregiving. By helping parents organize daily responsibilities, identify priorities, and recognize opportunities to ask for support, Mother encourages a more intentional and compassionate approach to recovery and family life.

## **Tech Stack**
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose

## **Features**
- Create, view, update, and delete tasks
- Organize tasks by category
- Track task completion
- Build a foundation for personalized recovery planning and support
- Project Status
