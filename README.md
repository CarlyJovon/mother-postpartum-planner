# Mother - Full Stack Postpartum Care Planning App
**Mothering the Mother**. Because mothers deserve to be cared for, too.

**Mother** is a postpartum recovery planning platform designed to help new moms navigate life after birth. By organizing daily tasks, creating realistic schedules, and coordinating support from partners and caregivers, Mother helps make postpartum recovery more manageable.

Powered by **Mother Voice**, the platform uses speech recognition to transform spoken input into actionable tasks, recovery goals, and scheduled rest periods.

## Key Features
- **Mother Voice**: Voice Input using Web Speech API
- **Task Management**: Create, view, update, and delete tasks to organize daily responsibilities
- **Recovery Planning**: Turn everyday responsibilities and personal priorities into manageable tasks and goals 
- **Daily Scheduling**: Plan tasks nd incorporate intentional rest periods into daily routines
- **Caregiver Coordination**: Make it easier to delegate tasks and coordinate support from partners and caregivers

## 🎙️Mother Voice

One of Mother's defining features is Mother Voice, which uses the browser's Web Speech API to support hands-free interaction. The goal is to reduce the mental load of managing daily responsibilities by allowing mothers to speak naturally instead of manually entering every task.

## Getting Started

Follow these instructions to run Mother locally.

# Prerequisites
- Node.js
- npm
- MongoDB Atlas account and connection string

# Installation

1. Clone the repo:
```bash
git clone https://github.com/CarlyJovon/mother-postpartum-planner.git
```

2. Navigate into the project directory:
```bash
cd Mother
```
3. Install dependencies
```bash
npm install
```
4. Create an `.env` file in the root directory and configure your environment variables:
```env
MONGODB_URI=your_mongodb_connection_string
PORT=3000
```

5. Start the application: 
```bash
npm start
```
6. Open http://localhost:3000 in your browswer
